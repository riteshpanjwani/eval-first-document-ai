# Security and data handling

All committed documents are fictional and generated in this repository. Uploaded files are processed
locally by default and should not be committed. `data/uploads/`, `.env`, and generated artifacts are
ignored by Git.

The optional LLM adapter sends only the selected document blocks to the configured API provider. Before
using real contracts, confirm retention, residency, access control, secret management, and deletion
requirements with the document owner.

Do not use this demo for legal advice or for decisions that require human legal review.
